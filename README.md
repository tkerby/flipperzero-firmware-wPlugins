# IRONWYRM

A turn-based modular mech fighting game for the Flipper Zero

Giant mechs rule the wasteland; strategically attach modular plates to your WYRM to survive as long as you can!

You can also play the [IRONWYRM web port](https://henrygurney.co.uk/games/) in your browser
