# BusterMan

A free Flipper Zero decoder companion from **DigitalEnigma**.

Decode Base64, hex, Brainfuck, and ROT13, or use the Auto chain mode. Successful decodes feed the companion and contribute to its XP and level progression.

## Project status

This repository is being prepared for an open-source release and submission to the official Flipper Apps Catalog. It is not yet a catalog listing or an installable release.

The existing device build uses the legacy display name "MegaMan Decoder". The next build will use **BusterMan**. Matching current source files must be recovered before that rename can be built and verified; older source archives are not a substitute for the current app.

Before submission, the project still needs the matching C source and application.fam, an open-source license, a catalog icon, unmodified qFlipper screenshots, and a successful build against supported official firmware.
