v2.0:
- Redesigned UI with custom sprites and animations
- Carousel main menu with icon tiles
- Saved Networks list with WiFi and lock icons and a scrollbar
- Confirm screen with per-field icons and Back/Del/Send buttons
- Animated transmit screen with progress bar; press Back to cancel a send
- Animated ACK wait with countdown, and result screens with Menu/Retry
- New NFC scan and About screens
- Non-WiFi NFC tags now show an error and scanning resumes automatically
- New app icon
- Added NEC IR protocol (38kHz) as an alternative to RC-6, selectable in Settings > IR Protocol

v1.0:
- Initial release
- Manual WiFi credential entry (SSID, password, security type, hidden toggle)
- NFC WiFi tag scanning (NTAG213/215/216, NDEF WiFi Simple Configuration)
- Saved networks (auto-save to SD card, browse, resend, delete)
- RC-6 IR transmission at 36kHz (optimized for ITE8708 CIR receivers)
- Optional ACK feedback from server (Settings > Wait for ACK)
- CRC-8 payload integrity verification
- Multi-pass retransmission support
