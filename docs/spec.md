# Системный Now Playing macOS → Flipper Zero по Bluetooth

## Задача

Показывать на Flipper Zero текущий медиапоток Mac без USB во время воспроизведения. Источником может быть любое приложение или вкладка браузера, которая публикует метаданные в системный Now Playing macOS. Привязки к Яндекс Музыке и браузерного расширения нет.

## Поведение

- Компаньон Mac читает активный Now Playing через локальный MediaRemote helper из `nowplaying-cli` и передаёт состояние по Bluetooth Low Energy. Текущая позиция рассчитывается из базовой позиции, метки времени и скорости воспроизведения.
- Flipper показывает название, исполнителя и альбом отдельными строками, а также состояние паузы, прогресс и доступную монохромную обложку. Источник медиа на экране не выводится.
- Русские названия передаются как UTF-8; длинные строки прокручиваются.
- Кнопки OK, Left и Right управляют активным системным медиаплеером: пауза/воспроизведение, предыдущий и следующий трек.
- Кнопки Up и Down изменяют системную громкость Mac с шагом 5%, если активное аудиоустройство поддерживает программную регулировку. Удержание повторяет команду.
- Если системного трека нет, Flipper показывает пустое состояние. После разрыва Bluetooth старый трек помечается `Reconnecting`, соединение восстанавливается автоматически.
- USB нужен только для установки приложения на Flipper и восстановления. Аудио остаётся на Mac, токены и внешний сервер не нужны.

## Реализация

- Flipper FAP адаптирован из `villenull/flipper-now-playing`; Mac-компаньон использует CoreBluetooth и локальный `nowplaying-cli`.
- Целевая прошивка первого выпуска: официальная Flipper Zero 1.4.3, API 87.1.
- Сборка и запуск описаны в [README](../README.md). Исходный протокол — в [constants.json](../protocol/constants.json).

## Проверка

- [x] FAP собран для API 87.1 и установлен на Flipper Zero с официальной прошивкой 1.4.3.
- [x] Mac-компаньон подключился по BLE; на Flipper отображаются трек и исполнитель.
- [x] На Яндекс Музыке проверены пауза, предыдущий и следующий трек.
- [x] На встроенных динамиках Mac проверены увеличение и уменьшение системной громкости с кнопок Flipper.
- [ ] Отдельно проверить переключение между двумя разными приложениями или браузером, отображение кириллицы и обложки, а также работу после отключения USB. Эти проверки пользователь решил отложить.

## Вне рамок

Передача аудио на Flipper, управление громкостью самого плеера отдельно от системы, браузерное расширение, собственная прошивка и публикация в официальном каталоге Flipper.
