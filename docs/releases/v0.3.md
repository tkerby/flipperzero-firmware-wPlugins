本次更新改善高速连打的音效叠加、圆弧和气球外观，并优化混音与内存使用。

## 更新内容

- 连打和气球的自动咚共用一个声部，下一击替换旧尾音，替换前做 3 ms 淡出；最后一击自然收尾，减少高速连打时的叠加失真。普通咚、咔仍可重叠播放。
- 自动连打上限提高至每秒 32 下，相当于 240 BPM 的 32 分音符，包含加速播放和相邻长音交界。
- 调整大咚、大咔、大连打两端和鼓面指示器的像素圆弧，减少突出的像素与不自然的阶梯。
- 气球移动时使用小音符尺寸的圆头，首次击打后扩大一圈；头部保持完整细黑圆环，颈部及膨胀尾部采用更平滑的像素轮廓。
- 混音时预先计算音效参数，跳过过期事件，同采样率时简化样本推进，减少重复计算。
- 复用绘制文本缓冲，统一停止音频与清除击打状态的处理。
- 音效和音频对象分配前检查内存余量，补齐音频启动失败时的资源清理及错误提示。
- 补充内存边界、静音和长短音效重叠的回归测试。

## 安装与升级

解压后将 `sdcard/` 内的内容复制到 SD 卡根目录，再从 **Media → Taiko Player** 启动。升级可覆盖对应文件，原有歌曲与 `settings.ff` 无需删除，设置格式保持兼容。

歌曲放在 `/ext/apps_data/taiko_player/songs/`；原始 OGG 需先用包内 `scripts/prepare_songs.py` 转换为 PCM WAV。详细步骤见包内 `INSTALL.md`。

暂不提供打击判定、分歧谱和保持音高的变速，不在设备上直接解码 OGG。
